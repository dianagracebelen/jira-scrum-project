# Online Shopping Web Application (OSWA) — QA Portfolio

## Project Overview
This project demonstrates my foundational knowledge of Jira, Scrum project organization, and manual software testing through a portfolio project based on Shopee's checkout and order placement workflows.

## Project Objectives
- Organize project work using Jira epics, user stories, and acceptance criteria.
- Design and execute manual test cases.
- Document actual results, execution statuses, and screenshot evidence.
- Prepare a QA test summary report.

## Jira Project Management
The project was organized in Jira using two epics:

- **Checkout Workflow:** Product quantity, delivery address, shipping fees, and payment methods.
- **Order Placement Workflow:** Adding products to the cart and placing an order.

User stories and acceptance criteria were documented under the corresponding epics. Work item statuses were updated to reflect completion.

## Testing Scope
Testing focused on user-visible checkout and order placement behavior on Shopee. Backend processes, internal systems, and unrelated website features were excluded.

## Test Artifacts
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Results and Screenshot Evidence
- QA Test Summary Report
- Jira Project Screenshots

## Test Execution Summary
Ten test cases were executed, and all ten passed. No confirmed defects were identified during testing. The out-of-stock scenario was not tested because a suitable out-of-stock product could not be found.
